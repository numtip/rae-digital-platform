# public/ — asset slots

ไฟล์ static ของเว็บ วางไฟล์จริงที่นี่ (ชื่อไฟล์ตามนี้เพื่อให้แก้ที่เดียว)

| ไฟล์ | ใช้ที่ | สถานะ |
|---|---|---|
| `logo.svg` | `components/site-header.tsx` (โลโก้หน่วยงาน) | ⏳ รอไฟล์จาก RAE |
| `hero.webp` | hero `/` (`app/page.tsx`) | ⏳ รอไฟล์จาก RAE (ห้ามใช้ hotlink ของ Google) |

ระหว่างรอ: hero ใช้สี `bg-brand-700` + ตัวอักษร เป็น placeholder (ไม่ใช้รูปปลอม) และโลโก้แสดงเป็นตัวอักษร `RAE`
