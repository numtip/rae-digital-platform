## ที่มาของรูปใน `images/about/`

- ต้นทาง: `https://rae.mju.ac.th/wtms_about.aspx?lang=th-TH` (หน้าเกี่ยวกับหน่วยงาน) — ดึงเมื่อ 2026-10-25
- ไฟล์ต้นฉบับบนเว็บ: `Logo_25580508150123_636182.png` (96×89), `Doc_25680618161335_315803.png` (1600×743), `Doc_25620208093802_726184.png` (719×505)
- แปลงเป็น WebP เฉพาะภาพถ่ายอาคารเพื่อลดขนาด (1.4 MB → 78 KB, 904 KB → 98 KB) · โลโก้คงเป็น PNG เพื่อความคม
- **ไม่นำเข้า** ภาพ 2 ใบที่มีตัวอักษรไทยฝังในภาพ (แถบปรัชญา/วิสัยทัศน์ 820×222) เพราะแปลเป็น EN ไม่ได้และโปรแกรมอ่านหน้าจออ่านไม่ได้ — หน้า about แสดงข้อความนั้นเป็น HTML แทน
- ใช้ในนามของหน่วยงานเอง (เนื้อหาและภาพเป็นของสำนักวิจัยและบริการวิชาการ มหาวิทยาลัยแม่โจ้)

ระหว่างรอไฟล์ที่เหลือ: hero ใช้สี `bg-brand-700` + ตัวอักษร เป็น placeholder (ไม่ใช้รูปปลอม) และโลโก้ใน header แสดงเป็นตัวอักษร `RAE`
เมื่อได้ไฟล์จริง: ใช้ `next/image` ในจุดที่กำกับ `TODO(issue #2)` ไว้ — ห้าม hotlink และต้องมี `alt` ที่สื่อความหมาย

## โลโก้มหาวิทยาลัยใน `images/brand/`

- ต้นฉบับ: `mju-emblem-source.jpg` (1280×1280, พี่ส่งมา 2026-10-26) — ตรามหาวิทยาลัยแม่โจ้ พร้อมข้อความโค้งด้านล่างที่ยังใช้ **ชื่อเดิม** ของสำนักฯ
- ตัดเฉพาะ **วงตรา** แล้ว mask พื้นหลังนอกวงเป็นโปร่งใส (`-vf geq` + `hypot`) เพื่อให้วางบน header เขียวเข้มได้โดยไม่มีกล่องขาว
- **ตัดข้อความโค้งชื่อเดิมออกโดยตั้งใจ** — เว็บใช้ชื่อใหม่ "สำนักวิจัยและบริการวิชาการ" ตามที่เจ้าของอนุมัติ การปล่อยชื่อเดิมในภาพจะเป็นการเผยแพร่ชื่อที่เลิกใช้แล้ว
- ได้ไฟล์ `mju-emblem-{96,192,256,512}.png` (โปร่งใส) · `app/icon.png` = 256px สำหรับไอคอนแท็บ
- alt text เรียกตามจริงว่า "ตราสัญลักษณ์มหาวิทยาลัยแม่โจ้" / "Seal of Maejo University" — ไม่ใช่ตราที่ออกแบบใหม่ให้สำนักฯ
