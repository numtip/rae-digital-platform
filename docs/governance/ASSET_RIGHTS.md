# Asset rights register

**Purpose.** Every asset in this repository that is *not* original source code, with where it
came from, what permission exists, and what its licence status is. Compiled on 2026-10-26 by
reading the files and their own provenance comments — not from memory.

**Status vocabulary**

| status | meaning |
|---|---|
| `EXCLUDED` | not covered by the Apache-2.0 LICENSE; see `NOTICE` |
| `PENDING` | needs a written decision or permission before it can be treated as reusable |
| `CLEARED-BY-DEPENDENCY` | third-party material already licensed by its owner; its own terms apply |

**Policy mapping** — each row below implements one clause of the owner's policy of 2026-10-26 as
written in `NOTICE` part A:

| clause | policy | rows |
|---|---|---|
| A1 | Maejo University materials and institutional media excluded | 1–6 |
| A2 | original application source code licensed under Apache-2.0 | (not listed here: it is the licensed code, see `NOTICE` A2) |
| A3 | third-party components keep their own notices and licences | 9, 11, 12 |
| A4 | documentation, research, blueprints, translations, design assets excluded | 2, 7, 8, 10 |

**Declared vs verified.** The status column is an implementation of the owner's *declared*
policy. What is *independently verified* is the origin of each item (the source URL or file
recorded in "Origin"), and what is *unresolved* is whether permission exists — stated per row
under "Permission held". `NOTICE` part C records the legal position that no assignment or
university IP regulation exists in this repository.

## What this register does not claim

- It does **not** assert that the office or the university has granted permission for items 1–7.
  It records that the material is published publicly by the office and that no written reuse
  permission exists in this repository.
- It does **not** resolve who owns the copyright in the original source code. See the
  "unresolved authority" section of `NOTICE` and `docs/governance/LICENSE_RECOMMENDATION.md`.
- It does **not** give legal advice. Items marked `PENDING` need a decision from the office head
  and, for the insignia in item 6, from the university.

## How to verify this register

```bash
# every content file states its origin in the first lines
head -6 content/th/about.ts content/th/news.ts content/th/site.ts

# which images exist and how they were produced
cat public/README.md

# the dependency licence spread quoted above
node -e 'const p=require("./package-lock.json").packages;const c={};
for(const[k,v]of Object.entries(p)){if(!k)continue;const l=v.license||"UNKNOWN";c[l]=(c[l]||0)+1}
console.log(Object.entries(c).sort((a,b)=>b[1]-a[1]))'
```
